# Air Force ASVAB Prep Pro V3

A single-file, responsive ASVAB preparation app with 540 independently authored practice items: 60 per subject. Includes 45-question diagnostic, 90-question timed mixed test, 40-question timed AFQT-focused test, subject drills, a missed-question deck, graphical rotation exercises, lessons, six-week schedule, local history and JSON backup/restore.

## Open locally on Windows

Open `index.html` in Edge or Chrome. No installation or internet connection is required.

## Open on iPad

For the most reliable Safari experience, publish `index.html` on a static HTTPS website. Local HTML opened from Files can be rendered as a preview rather than an interactive site.

## Publish with GitHub Pages (free)

1. Create a new public GitHub repository called `asvab-prep-pro`.
2. Upload `index.html` into the root of the repository.
3. Go to Settings → Pages → Build and deployment → Deploy from a branch.
4. Choose the `main` branch and `/ (root)`; save.
5. GitHub will report the actual live URL on the Pages settings screen. Open that URL in Safari on iPad, or share via WhatsApp.

Do not upload personal backup JSON files to a public repository. This is an original practice app, not affiliated with the Department of Defense. Practice percentages are not official AFQT percentiles.

## Data safety

Progress is browser-local and does not automatically sync. Use Backup / Restore to move results or protect them from device changes.
