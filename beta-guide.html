Help us make practice clearer.

Beta participation is free and optional. No payment, review, referral, or purchase is required. Early content can be wrong; verify important questions with qualified instruction. Never use these percentages as an official AFQT prediction.

A useful first session

  1. Open free ASVAB practice and export existing progress before testing.
  2. Take the 45-question diagnostic. Review the subject breakdown and explanations.
  3. Try a 20-question drill in a weaker subject, then missed-question review. Try the AFQT timed mode if useful; it is a practice format, not a reproduction of the real exam.
  4. Check keyboard navigation, text zoom, portrait/landscape layout, and whether answer explanations help you understand a mistake.
  5. Export a fresh backup. If invited, try an explicit private cloud save from your beta account and load it in a separate browser. Original V3 history is visible in My learning; restoring it into V3 itself requires that app's confirmed import.

Tell us what needs work

Invited testers can use the private feedback form in their account. Include a question ID, the step you took, expected behavior, and a short description. A report is not a verified correction until reviewed. Do not include personal scores, emails, passwords, invitation links, card information, backups, school or military records.

Public technical reporting is available for nonprivate information. Private support operations still require owner setup before public recruitment. Do not post account or privacy requests publicly.

Payments are not part of this beta

The planned Exam Pass is $19.99 for 90 days. It is not on sale. Only specifically invited payment testers should use the optional test checkout, with Stripe's documented test details. Do not use a real card. Beta access does not convert to a paid subscription.

What still needs human testing

Actual iPhone/iPad Safari, Android Chrome, Windows browsers, screen readers, 200–400% zoom, and interrupted network/storage conditions need real-device review. Automated Chromium checks do not certify accessibility. Qualified independent educators must review question accuracy, explanations, ambiguity, distractors and learning usefulness before a paid release.
